# UML Class Diagram-to-Text Translator

This folder contains the final version of the UML Class Diagram-to-Text Translator developed as part of this research study.

The artefact generates two forms of textual output from UML class diagrams exported in SVG format:

- Literal translation, which describes the graphical content of the UML class diagram.
- Model translation, which describes the UML meaning represented by the diagram.

## Download the artefact

The final version of the UML Class Diagram-to-Text Translator can be downloaded from the following release:

[Download UML Class Diagram-to-Text Translator v1.0.0](https://github.com/bessaacg/UML-Class-Diagram-Translations/releases/tag/v1.0.0)

The release package contains the application installer and the UMLet components required by the artefact.
